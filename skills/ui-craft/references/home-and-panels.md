# 智能家居面板与低注意力界面

家居控制面板装在走廊、门口或厨房，用户路过时用一两秒操作，手上可能拿着东西，环境亮度可能很低或很亮。它更接近工业面板而不是手机 App。

## 从物理位置决定 UI

| 安装位置 | 用户状态 | 设计取舍 |
| --- | --- | --- |
| 门厅 | 出门或回家，几秒内 | 只放全屋情景和灯光总控；细节进入房间页 |
| 走廊 | 路过，手可能占着 | 大热区、少层级、无滑动才能到达的内容 |
| 厨房 | 手湿、油烟 | 表面易清洁，避免小按钮；语音作为主入口 |
| 卧室 | 睡前，环境暗 | 极低亮度、无蓝光白字、操作后自动降亮 |

## 显示实测与设定

**两个温度不能混。** 实测温度与设定温度是不同概念。实测用常规字重，设定值放在旋钮中心并加单位；两者相差超过 0.5 °C 时才标注偏差，否则不额外提示。

**旋钮即控件。** 旋钮本身可旋可点，旁边的 − / + 是同一动作的备份。旋钮与加减键触发同一段逻辑，不能各自维护一份状态。

**情景要写清影响。** 切换「离家」时，明确说出影响了哪几个房间、各做了什么。只说「已切换」会让人不确定水电是否都断了。

**状态要能固定。** 面板不是通知中心。需要保留的提示（滤网到期、排风累计时长）固定在一个区域，不弹窗、不自动消失。

## 低亮度与夜间

- 夜间配色避免纯白字：用 #e8dcc8 一类暖纸色，屏幕最低亮度可到 3—5 nit。
- 操作后 8—15 秒自动降亮，但保留最关键的一条状态（如「客厅 22 °C」）。
- 触摸面板在黑暗中难以定位，关键按钮可加轻微的物理凸起或背光提示。
- 不做持续动画。呼吸灯、渐变光效在卧室会被视为干扰。

## 可靠性与隐私

**断网降级。** 云服务不可用时，本地情景与灯光控制应继续工作，界面标注「本地模式」，不要整屏报错。

**延迟反馈。** 家电状态变化常有一两秒延迟。点击后立即给出本地乐观状态，并在真实回执到达后纠正；不要让人重复点击。

**麦克风与摄像头。** 有麦克风的面板必须在物理上能关闭，且关闭状态可被一眼确认。语音唤醒的错误触发要有可撤回的提示。

**多用户。** 同一面板会被家中多人使用。个人偏好（温度、亮度）与共享情景分开存储；不要把一个人的设置自动套给所有人。

## 与其他设备协同

同一套控制在手机 App、面板、语音助手三处出现时，状态与命名必须一致。手机可以做复杂编排，面板只做即时控制，语音做单手可达的动作。三者操作后彼此的显示要在数秒内同步。

## 验证

- 在 5% 与 100% 亮度下各看一次，确认关键状态仍可读。
- 只用手背或指关节操作（模拟手上有东西），检查热区是否够大。
- 断网后重试灯控与情景，确认降级提示清楚。
- 让两个人分别调整温度，确认各自偏好不互相覆盖。
- 检查夜间自动降亮后，再次触摸是否能立即恢复到可读亮度。
